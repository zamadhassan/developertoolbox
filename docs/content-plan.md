# Content Plan

## Core Public Pages

- `/`: landing page and tool discovery directory.
- `/tools`: complete searchable tool directory.
- `/tools/[slug]`: individual indexable tool pages.
- `/categories/[slug]`: category landing pages with contextual content.
- `/blog` and `/blog/[slug]`: local article system.
- `/about`, `/contact`, `/privacy-policy`, `/terms`, `/disclaimer`, `/cookie-policy`, `/editorial-policy`, `/open-source`.

## Blog Starter Topics

The starter article library should be written after the pilot tool registry exists so posts can link naturally to real tool pages. Priority topics:

- Essential Browser-Based Tools Every Developer Uses
- How to Format and Validate JSON Safely
- UUID Versions Explained: Which One Should You Use?
- Base64 Encoding and Decoding Explained
- Hashing vs Encryption: What Is the Difference?
- How to Decode a JWT Without Exposing Sensitive Data
- Common Regular Expression Testing Mistakes
- URL Encoding Explained for Web Developers
- Unix Timestamps and Date Conversion Explained
- JSON vs YAML: When to Use Each Format

## Content Quality Rules

- No lorem ipsum.
- No fake testimonials, ratings, statistics, or user counts.
- No copied competitor content.
- Tool pages must include tailored instructions, examples, limitations, privacy notes, FAQs, and related internal links.
